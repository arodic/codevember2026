#### Codevember Fold (procedural TSL terrain, src/days/fold)

- **Height-field GI pattern:** radiance compute (albedo/pi*(direct+own irr)) + gather compute (cos rays over coarse height; miss -> CPU sky radiance map) + edge-aware filter (tangent-plane distance) + running average 1/n (caps by change kind). Store irradiance / scene light level, else long averages keep daylight into night (pre-exposure rescale x1e5 -> white-out). Shorten history by drift of ln(level).
- **Overhangs on height field:** sideways vertex shift up coarse slope by recess(height); crest fade near wall top avoids flaps; normal = central diff of shifted positions; marches don't see it -> per-texel lip angle for lip shadow/AO.
- **Debug lesson:** removing a lighting term that also brightens the frame hides artifacts in other terms (indirect); isolate by disabling candidates one at a time with lighting held (AO-off found sand contour stripes).
- **Grazing light:** anything projected along the key light (cloud shadows, marches) moves ∝ 1/sin² -> fade by smoothstep(0.06, 0.3, key.y) (CLOUD_SHADOW_FADE); fade to a value equal to the other branch so horizon switch is seamless.
- **Sub-pixel splats:** star kernel must be well sampled: tent at 1 px half-width = exact constant energy; Gaussian exp(-4r²) needs ≥1.5 px half-width. Undersampled -> 0..5× flashes.
- **NaN -> flash:** GPU min(NaN, cap) returns cap -> a NaN pixel becomes the brightest value, bloom spreads it. Clamp asin/acos inputs of rotated/normalized vectors (poles, zenith round past ±1). Find one-frame spots: isolated-bright-pixel detector vs neighbor frames, then toggle bloom / objects.
- **RGB lighting:** saturated Preetham sky x orange albedo -> olive shade; temper sky light chroma (keep luminance) for lighting only.

#### Codevember Feather (src/days/feather)

- **WebGPU compute traps:** (1) max storage buffers per compute stage = 8 -> pack related `vec4` arrays with offsets (`<= 7` bindings); (2) `WorkgroupInfoNode.element(idx)` does NOT wrap raw JS numbers -> pass `int(idx)` (`sharedArray` helper); (3) `cameraPosition` (`render.cameraPosition`) inside a shared layout `Fn` fails WGSL (`unresolved value 'render'`) -> compute `viewDir` in caller and pass as arg; (4) JS unary `-node.x` evaluates to `NaN` (`NaN.0` in WGSL) -> always `.negate()`.
- **ThreeViewport subclass trap:** `ready()` runs inside `super()` BEFORE `ThreeViewport`'s class field `readonly inputRouter = new InputRouter(this)` exists -> install router `Behavior`s in subclass `constructor` after `super(args)`.
- **Premultiplied hair + real-time DoF:** draw back-to-front (`One, OneMinusSrcAlpha`, `depthWrite: false`) first, then a fast `colorWrite: false, depthWrite: true` ribbon corridor pass (`|v| <= 0.76`) so `scenePass.viewZ` gets continuous filament depth without alpha-cutout fringes; prefilter + 9-tap tent postfilter eliminates Vogel disc stippling.
- **Feather core jitter (fixed):** rest pose crowded (75% collision nodes overlap, up to 19 nbrs) -> contacts fought elastic pull every substep; plus pass 1A never stored velocity, 1B added push/dt onto stale vel -> pushes became lasting velocity (energy pump). Fix: PBD vel (p_end - p_start)/dt (1A stores, start vel parked in stemAux frame slot, rewritten by Bishop pass), contact radius rest-relative (`restOverlap`), pushes summed then capped at largest single, only `contactBounce` of push -> velocity, velcro + structural damping relative to socket vel. Params on Feather: stemDamping, barbuleDamping (Physics), envelopeScale/contactStiffness/contactDamping/contactBounce/restOverlap (Contacts). User: "perfect".
- **TSL read-after-write trap:** a storage `element()` read is re-emitted at each use, so a read used after that element is assigned sees the NEW value -> `.toVar()` reads before the assign (pOld, vOld, curPos, rootVel, pSolved).
- **Jitter metric:** headless, pause timeline, step currentTime 1/60 + `vp.tag('content')`, read `renderer.getArrayBufferAsync(physics.stemPosBuffer)` per frame, per-node RMS of 2nd time difference (median vs p99), plus air 0 drift after long settle (should -> 0).
- **Feather rig/sound/fade:** camera child of `CameraRig` (pivot = pose target, rotation.y = orbitTurns·2π·t/dur), backdrop child of rig at -target (shader uses positionLocal), key/fill + volume keyDirection rotated per frame -> studio rides rig. Soundtrack shared `src/Soundtrack.ts` (Fold converted). `src/TimelineFade.ts` (moved from fold/) has `color`; Neutral tone mapping -> display-space crossfade via exact inverse PBR Neutral (cap 0.998); else linear mix (Fold black unchanged). Air phase = round(dur/32) cycles per loop. Feather's FeatherVolume field renamed `lightVolume` (audio prop is `volume`).
- **Headless trap:** first frames after load show IoCodevember's cover lifting (vignette-like 229 corners at t=0): wait ~3 s before sampling pixels.
- **`NodeMaterial.fragmentNode` + MRT (`traa` axis views) trap:** in Three r187 `NodeMaterial.setup()`, setting `material.fragmentNode` bypasses the MRT block (`if (this.fragmentNode === null) { ... mrt ... }`), AND `WebGPUBackend.getRenderCacheKey` checks only `textures[0]` format, not attachment count. Result: 1-target (`Active`/`Perspective`) and 2-target (`traa` ortho axis views: `output` + `velocity`) share one `GPURenderPipeline` (`colorTargets.length = 1`) -> WebGPU attachment-state validation error in non-fullscreen mode. Fix: use `material.colorNode` (keeps `fragmentNode === null` so MRT runs) + `material.positionNode` (with `positionPrevious.assign(worldVertex)` so `VelocityNode` doesn't smear) + parallel-ray `isOrtho` ribbon basis.
